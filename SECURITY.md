# Security Policy

CloudGuard is a security-focused open-source project.

## Reporting Vulnerabilities

Please do not publicly disclose security vulnerabilities. Instead, please report them via email to biti_gchar@simplelogin.com or via GitHub Security Advisories.

Please provide:
- Description of the vulnerability
- Affected component
- Steps to reproduce
- Potential impact

## Supported Versions

Security updates are provided for actively maintained versions.

## Responsible Disclosure

We appreciate responsible security research and collaboration.
